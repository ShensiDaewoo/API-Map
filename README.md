# 어디까지 가나요? — 거리 측정

출발지와 도착지를 검색해 실제 장소를 선택하고 자동차 경로 거리와 예상 시간을 확인하는 정적 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열거나, 프로젝트 폴더를 정적 사이트로 제공하면 됩니다. 빌드 명령, 서버리스 함수, Redis, API 키, 환경변수는 필요하지 않습니다.

## Vercel 배포

1. 프로젝트 파일을 GitHub 저장소에 올립니다.
2. Vercel에서 **Add New → Project**를 선택하고 저장소를 Import합니다.
3. Framework Preset은 **Other**로 두고 Build Command는 비워 둡니다. Output Directory는 프로젝트 루트(`.`)로 지정합니다.
4. 배포합니다. 환경변수 설정은 필요하지 않습니다.

## 데이터 제공자 및 제한

- 장소 검색: [OpenStreetMap Nominatim](https://nominatim.org/)
- 자동차 경로 및 거리·예상 시간: [OSRM 공개 데모 서버](https://project-osrm.org/)
- 지도 링크: OpenStreetMap 길찾기

Nominatim 검색은 사용자가 검색 버튼을 누르거나 Enter를 입력했을 때만 요청합니다. 클라이언트는 요청 간격을 1.1초 이상으로 제한하지만, 이 제한은 브라우저 한 개 안에서만 적용됩니다. 공개 Nominatim 서비스는 전체 사용자 트래픽에 대해 초당 최대 1건 및 공정 사용 정책을 적용하며, 대량·상업적 사용이나 서비스 수준 보장이 필요한 경우에는 별도 서비스 제공자 또는 자체 호스팅을 검토해야 합니다. OSRM 공개 데모 서버 역시 서비스 수준을 보장하지 않으며, 과도한 트래픽에는 적합하지 않습니다.

검색어는 Nominatim으로 전송됩니다. 지도 데이터 출처를 앱에 표시하고 있으며, 외부 데이터 제공자의 운영 정책 및 가용성에 따라 검색·경로 기능이 제한될 수 있습니다.
